# TVBox Web - Meow 多资源站影视播放器

一个基于 **Cloudflare Workers** 的轻量级 Web 影视聚合播放器，兼容 Meow / TVBox 资源站配置格式。

无需购买服务器，无需搭建后端，直接部署到 Cloudflare Workers，即可通过浏览器访问，聚合多个影视资源站，实现影片分类浏览、在线播放、搜索、线路切换及观看历史记录等功能。

## ✨ 项目介绍

TVBox Web 是一个基于 Cloudflare Workers 的多资源站影视播放器。

项目通过读取 Meow JSON 配置文件，自动获取多个影视资源站的数据，并提供统一的 Web 播放界面。

采用 HTML、CSS、JavaScript 构建前端页面，使用 Cloudflare Workers 处理跨域代理请求，无需单独部署前端服务器。

## 🚀 主要功能

- **多资源站聚合**：支持读取 Meow JSON 配置，自动加载多个影视资源站。
- **资源站切换**：支持在不同资源站之间自由切换。
- **影片分类**：自动读取资源站分类，按分类浏览影片。
- **影片搜索**：支持按影片名称、演员等关键词搜索。
- **影片详情**：展示影片海报、名称、年份、地区、类型及剧情简介。
- **多线路播放**：支持同一影片切换不同播放线路。
- **剧集选择**：支持电视剧、连续剧等多集内容选择。
- **网页在线播放**：使用 HTML5 Video 播放器。
- **HLS 播放支持**：集成 HLS.js，支持浏览器播放 M3U8 视频。
- **VLC 播放**：支持调用 VLC 播放器打开视频地址。
- **观看历史**：自动保存观看记录，包括影片、资源站、剧集及播放进度。
- **续播功能**：支持从观看历史中恢复影片及上次播放位置。
- **历史管理**：支持查看和清空观看历史。
- **自定义配置**：支持修改 Meow JSON 配置文件地址。
- **跨域代理**：通过 Cloudflare Workers 代理资源站请求。
- **域名白名单**：限制配置文件和代理目标域名。
- **响应式布局**：适配电脑、平板及手机浏览器。
- **无需数据库**：观看历史使用浏览器 LocalStorage 保存。

## 📦 部署教程

### 1. 创建 Cloudflare Worker

1. 登录 [Cloudflare](https://dash.cloudflare.com/)。
2. 进入 Workers & Pages。
3. 点击创建应用程序。
4. 选择创建 Worker。
5. 设置 Worker 名称，例如 `tvbox-web`。
6. 创建完成后进入代码编辑页面。

### 2. 部署代码

1. 打开 Worker 代码编辑器。
2. 删除默认示例代码。
3. 将项目中的完整 Worker 源代码复制进去。
4. 点击部署（Deploy）。
5. 部署成功后即可通过 Cloudflare 分配的 Worker 地址访问播放器。

访问地址示例：

```text
https://你的Worker名称.你的Cloudflare账户.workers.dev
```

### 3. 配置环境变量（可选）

进入 Cloudflare Worker：

Settings → Variables and Secrets

根据需要添加以下环境变量：

| 变量名称 | 默认值 | 说明 |
|---|---|---|
| CONFIG_URL | Meow 默认 JSON 地址 | 默认资源站配置文件地址 |
| ALLOWED_CONFIG_HOSTS | raw.githubusercontent.com | 允许读取配置 JSON 的域名，多个域名使用英文逗号分隔 |
| ALLOWED_PROXY_HOSTS | 空 | 额外允许代理访问的公开域名，多个域名使用英文逗号分隔 |

默认配置文件：

```text
https://raw.githubusercontent.com/anaer/Meow/main/meow.json
```

**注意：**

- `CONFIG_URL` 用于设置默认配置文件地址。
- `ALLOWED_CONFIG_HOSTS` 用于限制允许读取配置 JSON 的域名。
- `ALLOWED_PROXY_HOSTS` 用于额外添加允许代理的域名。
- 自定义配置文件域名必须加入 `ALLOWED_CONFIG_HOSTS`。
- 修改环境变量后，确保配置已生效。

## ⚙️ 使用说明

### 1. 打开播放器

部署完成后，通过 Worker 地址打开播放器。

首次打开时，系统会自动读取默认 Meow 配置文件。

### 2. 切换资源站

在页面右上角的资源站下拉菜单中，可以选择不同的影视资源站。

### 3. 浏览影片

- 点击分类标签浏览影片。
- 点击影片海报进入详情页面。
- 查看影片简介、年份、地区及其他信息。

### 4. 搜索影片

在首页搜索框输入影片名称或关键词，点击搜索即可查询当前资源站中的相关影片。

### 5. 播放影片

进入影片详情页面：

1. 选择播放线路。
2. 选择需要播放的剧集。
3. 点击「网页播放」开始播放。
4. 如果网页无法播放，可以尝试「使用 VLC 播放」。

### 6. 观看历史

点击页面顶部的「历史」按钮，可以查看之前播放过的影片。

观看历史包含：

- 影片名称
- 影片海报
- 所属资源站
- 当前播放剧集
- 上次播放位置

点击历史记录可以尝试继续播放。

观看历史保存在当前浏览器的 LocalStorage 中，不同浏览器、不同设备之间不会自动同步。

### 7. 修改配置文件

点击页面右上角「配置」按钮，可以输入新的 Meow JSON 配置地址。

配置文件需要包含 `sites` 数组，每个资源站至少需要提供 `api` 字段。

示例结构：

```json
{
  "sites": [
    {
      "name": "资源站一",
      "api": "https://example.com/api.php/provide/vod/"
    },
    {
      "name": "资源站二",
      "api": "https://example.org/api.php/provide/vod/"
    }
  ]
}
```

以上仅为配置格式示例，实际使用时请替换为有效的资源站 API 地址。

## 🔒 代理及安全说明

本项目通过 Worker 的 `?proxy=` 参数实现代理功能。

代理请求具有以下限制：

1. 仅允许 HTTP / HTTPS 协议。
2. 禁止常见本地及私有 IP 地址。
3. 配置文件域名需要通过 `ALLOWED_CONFIG_HOSTS` 白名单验证。
4. 代理目标域名必须符合配置文件资源站域名或额外代理白名单。
5. 代理响应支持 CORS 跨域请求。
6. 代理响应默认不缓存。

**安全提示：**

本项目的代理服务没有用户身份验证，部署后应谨慎管理白名单，不建议随意开放额外代理域名。

同时，当前代码的域名校验主要针对常见 IP 字面地址，并不能完全替代完整的 DNS 重绑定防护及私网地址校验。正式公开部署时，建议进一步完善网络层安全限制。
